Medium Deprecation RULE-DEPR-002: Deprecated API: pkg_resources Imported Directly

Package: setuptools

linkwatch imports pkg_resources to locate template assets. Setuptools has formally deprecated pkg_resources, and it generates a runtime DeprecationWarning.

Rationale: pkg_resources has slow import overhead and is scheduled for retirement. Standard library 'importlib.resources' (available in Python 3.9+) is the modern, zero-dependency replacement.

Action: Replace pkg_resources with importlib.resources.files() from the Python standard library.

Observed Evidence (1 locations)
