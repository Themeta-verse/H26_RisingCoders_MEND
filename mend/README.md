MEND (**Migration Evidence & Dependency Navigator**) is an evidence-first dependency resilience and migration engine. Rather than focusing exclusively on CVE databases, MEND focuses on **Dependency Resilience**: discovering breaking transitive pairings, manifest specifier drift, dead/obsolete libraries, and unreferenced phantom dependencies, and using local **Gemma 4** (`gemma4:e2b-it-q4_K_M`) via Ollama to generate verified migration paths.

## Non-Negotiable Operational Principles

1. **Strict Epistemic Separation**:
   - **Tier 1: Observed Facts**: Concrete AST import snippets, exact manifest lines, installed versions, and raw test exit codes.
   - **Tier 2: Static Rules**: 8 deterministic resilience rules (e.g., transitive incompatibility, manifest conflict, abandoned libraries, deprecated APIs).
   - **Tier 3: AI Advisory**: Non-authoritative guidance generated by local Gemma 4 via Ollama. Always labeled as AI-generated recommendations.
   - **Tier 4: Empirical Proof**: Subprocess `pytest` execution outcomes from isolated sandbox candidate runs.
2. **Zero Target Repository Mutation**: The target codebase (`LinkWatch/`) remains pristine and read-only. Candidate experiments execute in temporary sandbox clones using prioritized `PYTHONPATH` overrides.
3. **100% Zero-Cost Local Inference**: Powered entirely by `gemma4:e2b-it-q4_K_M` via local Ollama. No cloud dependencies, paid tokens, or external API keys required.

## REST API Endpoints

| Endpoint | Method | Description |
| :--- | :---: | :--- |
| `/api/status` | `GET` | System health check, Ollama availability, model tag verification, active repository info. |
| `/api/scan` | `GET` | Deterministic AST and manifest scan of active repository. |
| `/api/scan/diff` | `GET` | Snapshot drift diff comparing previous and current scans. |
| `/api/rules` | `GET` | Evaluate 8 deterministic resilience rules on scanned evidence. |
| `/api/dependency-intelligence` | `GET` | Side-by-side version comparison against official PyPI registry with official links. |
| `/api/recommend` | `POST` | Invoke local Gemma 4 model with bounded context for a specific package. |
| `/api/recommendations` | `GET` | Retrieve cached migration recommendations for active repository. |
| `/api/verify/baseline` | `POST` | Execute baseline tests in the target repository's existing virtual environment. |
| `/api/verify/candidate` | `POST` | Execute candidate test verification in an isolated sandbox clone. |
| `/api/ledger` | `GET` | Retrieve Migration Integrity Lifecycle Ledger with SHA-256 digests. |
| `/api/integrity` | `GET` | Manifest Snapshot SHA-256 digest, capsule file hashes, and safety specifications. |
| `/api/capsule/generate` | `POST` | Build and return complete Dependency Exit Capsule JSON payload. |
| `/api/capsule/download` | `GET` | Download versioned Dependency Exit Capsule as a `.json` file. |
| `/api/capsule/report` | `GET` | Download standalone zero-dependency executive HTML report. |
| `/api/repositories/list` | `GET` | List registered repositories (LinkWatch benchmark + imported GitHub repos). |
| `/api/repositories/select` | `POST` | Switch active repository context with strict data isolation. |
| `/api/repositories/add` | `POST` | Clone public GitHub repository (`git clone --depth 1`) into dedicated workspace. |
| `/api/repositories/sync` | `POST` | Fetch latest revision from origin for cloned repositories (protected on LinkWatch). |
| `/api/repositories/refresh` | `POST` | Force refresh scan on active repository. |

## Getting Started

### Prerequisites
- Python 3.12+
- Node.js v18+ (tested on v24.19)
- Ollama running locally with `gemma4:e2b-it-q4_K_M`:
  ```bash
  ollama pull gemma4:e2b-it-q4_K_M
  ```

### Installation
From the repository root:
```powershell
# Windows PowerShell:
python -m venv mend/.venv
.\mend\.venv\Scripts\Activate.ps1
pip install -r mend/requirements.txt
```

```bash
# Linux / macOS / Bash:
python -m venv mend/.venv
source mend/.venv/bin/activate
pip install -r mend/requirements.txt
```

### Running MEND Backend
```bash
# Starts FastAPI server and mounts the pre-built React frontend at http://127.0.0.1:8000
python -m uvicorn mend.api.main:app --host 127.0.0.1 --port 8000
```

## Running Automated Tests

Run the full MEND backend pytest test suite (33 tests across 6 suites):
```powershell
# Windows PowerShell:
$env:PYTHONPATH='.'
.\mend\.venv\Scripts\python -m pytest mend/tests -v
```

```bash
# Linux / macOS / Bash:
PYTHONPATH=. ./mend/.venv/bin/python -m pytest mend/tests -v
```

All 33 tests execute cleanly:
- `mend/tests/test_adapters.py`: Ecosystem detection and handling (3 tests).
- `mend/tests/test_api.py`: FastAPI endpoints, status, scan, drift diff, intelligence, rules, ledger, repositories, and capsules (21 tests).
- `mend/tests/test_capsule.py`: Schema 1.0.0 validation and SHA-256 embedding (1 test).
- `mend/tests/test_model_client.py`: Structured JSON parsing, schema error recovery, and stdlib fast-path (4 tests).
- `mend/tests/test_rules.py`: Deterministic resilience rule detections on LinkWatch (1 test).
- `mend/tests/test_scanner.py`: AST parsing, manifest conflict detection, name normalization, and datetime deduplication (3 tests).
